QuietSafari

For Safari on Mac. No subscription, and no paid Apple developer account.

A quieter
Safari.

Hides banners, trackers, YouTube ads, and Yandex ads on other sites. Yandex search and maps stay put.

Download for Mac GitHub
brew install --cask --no-quarantine rubpf/tap/quietsafari

macOS 14 or later.

What goes quiet

YouTubePre-rolls are stripped from the player response before they start.
BannersEasyList hides ordinary display ads and the empty slots they leave.
TrackersEasyPrivacy, including Yandex Metrica.
YandexYandex and Adfox ads on other sites. Not search, and not maps.

Three steps

1
Download and open

Unzip QuietSafari.zip. If macOS says the app is damaged, open System Settings → Privacy & Security → Open Anyway. Or run xattr -dr com.apple.quarantine on the app.

2
Allow unsigned extensions

Safari → Settings → Advanced → Show features for web developers. Then Develop → Allow Unsigned Extensions. Safari turns this off every time you quit it.

3
Four checkboxes

Extensions: QuietSafari, Content Blocker, Privacy, and Russian. Allow QuietSafari on every website. The app shows these steps the first time it opens.

FAQ

Why do the checkboxes reset?

This build has no paid Apple signature. Safari turns off Allow Unsigned Extensions when it quits. QuietSafari then says the permission was reset, with a button back to the settings.

Does anything leave this Mac?

No. Rules and settings stay on this computer. Update filters only downloads the public EasyList, EasyPrivacy, and RU AdList files.

Which macOS?

macOS 14 or later. This build does not cover iPhone.
