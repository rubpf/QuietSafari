# QuietSafari

Блокировщик рекламы для Safari на Mac. Вы открываете проект в Xcode, один раз выбираете свою бесплатную команду и нажимаете Run. Программировать для этого не нужно.

Эта версия — каркас. Она уже прячет несколько очевидных рекламных блоков и обрывает запросы к известным рекламным сетям, а на YouTube пробует пропустить ролик. Полные списки EasyList и EasyPrivacy подключаются на следующем этапе. Как устроено и что дальше: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) и [docs/ROADMAP.md](docs/ROADMAP.md).

## Что понадобится

- Mac с macOS 14 или новее.
- Xcode 16 или новее из App Store. При первом запуске Xcode дождитесь, пока он доставит дополнительные компоненты.
- Обычный Apple ID. Платная программа разработчика не нужна.

Папку `scripts` запускать не нужно. Проект уже собран, открывается файл `QuietSafari.xcodeproj`.

## Открыть и запустить

1. Распакуйте или склонируйте эту папку на Mac. Не запускайте файл `.app` из папки вручную — его там нет. Приложение создаёт Xcode.
2. Откройте Xcode → Settings (Настройки) → Accounts (Учётные записи) и добавьте свой Apple ID, если его ещё нет. В списке появится Personal Team — ваше имя с пометкой Personal Team.
3. В Finder дважды щёлкните `QuietSafari.xcodeproj`.
4. Если Xcode предложит обновить настройки проекта (Update to recommended settings / «Обновить до рекомендуемых настроек») — нажмите **Perform Changes**. Это безопасно.
5. Сверху слева, рядом с треугольником Run, должно быть написано **QuietSafari** и **My Mac**. Если нет — выберите их в этих меню.
6. Слева щёлкните синюю иконку проекта QuietSafari. В центральной колонке откройте TARGETS и по очереди выберите три цели:
   - QuietSafari
   - QuietSafariExtension
   - QuietSafariContentBlocker

   У каждой откройте вкладку **Signing & Capabilities** (Подпись и возможности). Поставьте галочку **Automatically manage signing** (Управлять подписью автоматически). В меню **Team** (Команда) выберите одну и ту же Personal Team. Команда должна совпадать у всех трёх, иначе окно и Safari не увидят общие настройки.
7. Нажмите Run (треугольник) или клавиши Command+R.
8. Если Xcode спросит пароль от связки ключей — это пароль вашего Mac. Введите его и нажмите Always Allow (Всегда разрешать).
9. Должно открыться окно QuietSafari.

Если Xcode пишет, что идентификатор `com.quietsafari.macos` занят, откройте в Xcode файл `Config/Shared.xcconfig` и замените `com.quietsafari.macos` на что-нибудь своё, например `com.вашеимя.quietsafari`. Сохраните и нажмите Run ещё раз.

## Включить в Safari

Сборка из Xcode для Safari считается неподписанной для магазина. Без двух галочек ниже расширения молчат. Это ограничение Safari, не ошибка проекта.

1. Откройте Safari → Настройки (Settings) → вкладка **Дополнительно** (Advanced).
2. Внизу включите **Показывать функции для веб-разработчиков** (Show features for web developers).
3. В строке меню появится пункт **Разработка** (Develop). Откройте его и включите **Разрешить неподписанные расширения** (Allow Unsigned Extensions). macOS спросит пароль.
4. Safari → Настройки → **Дополнения** (Extensions).
5. Включите оба пункта:
   - **QuietSafari**
   - **QuietSafari Content Blocker**
6. Выберите QuietSafari и разрешите ему все сайты: **Всегда разрешать на всех веб-сайтах** (Always Allow on Every Website).

Когда вы полностью закрываете Safari, пункт «Разрешить неподписанные расширения» выключается сам. Перед следующей проверкой включите его снова. Бесплатная подпись также протухает примерно через семь дней: приложение перестанет открываться, просто снова нажмите Run.

После каждого нового Run Safari иногда сам снимает галочки расширений, потому что подпись сборки изменилась. Если блокировка пропала после пересборки — загляните в Дополнения и включите оба пункта ещё раз.

## Проверить, что реклама скрывается

1. Окно QuietSafari должно быть открыто, оба расширения включены.
2. Нажмите **Открыть проверочную страницу**.
3. Если macOS спросит, можно ли принимать входящие соединения — нажмите **Разрешить**. Страница открывается только на этом компьютере, в интернет она ничего не слушает.
4. В Safari откроется страница «Проверка QuietSafari».
   - Красных прямоугольников со словом **РЕКЛАМА** быть не должно.
   - Зелёный абзац «Этот блок должен быть виден» должен остаться.
   - Строка про рекламную сеть должна сказать, что адрес не загрузился. Для этой строки нужен интернет и включённый **QuietSafari Content Blocker**. Обновите страницу, если открыли её раньше, чем включили расширение.
5. Вернитесь в окно QuietSafari. Через несколько секунд счётчик «Отмечено на страницах» может увеличиться. Он растёт, только если включено расширение QuietSafari (не Content Blocker): сетевые обрывы Safari в этот счётчик не сообщает.
6. На панели Safari появляется кнопка QuietSafari. В ней то же состояние и тот же счётчик.

YouTube этой страницей не проверяется. Откройте youtube.com и включите ролик: баннеры в ленте должны попрятаться, короткий рекламный ролик — пропуститься. Обычное видео должно играть. Это базовая попытка. Если YouTube уже успел сменить страницу, ролик может не пропуститься — на каркас это не влияет, проверочная страница важнее. Полная поддержка YouTube описана в дорожной карте.

Белый список можно проверить так: добавьте `127.0.0.1`, обновите проверочную страницу — красные блоки должны вернуться. Удалите адрес и обновите страницу ещё раз.

## Если что-то пошло не так

**Окно не открылось, Xcode красным пишет про App Groups или capability.**  
Бесплатная команда иногда спотыкается именно на общей папке. Блокировка по встроенному списку может работать и без неё. Откройте три файла и в каждом удалите блок из четырёх строк `com.apple.security.application-groups` (ключ и весь `array` под ним):

- `App/QuietSafari.entitlements`
- `Extension/QuietSafariExtension.entitlements`
- `ContentBlocker/QuietSafariContentBlocker.entitlements`

Нажмите Run снова. Выключатель и белый список заработают только когда общая папка подпишется; проверочная страница и встроенные правила — уже без неё.

**В окне написано, что общая папка недоступна.**  
У трёх целей должна быть выбрана Team, не пункт None и не пустая подпись «Sign to Run Locally» без команды. Команда одна и та же. После смены команды нажмите Run ещё раз.

**В Safari нет дополнений.**  
Сначала хотя бы раз откройте приложение кнопкой Run. Потом полностью закройте Safari и откройте снова. Проверьте меню Разработка → Разрешить неподписанные расширения.

**Дополнения есть, но красные блоки на месте.**  
Включены ли оба. У QuietSafari выбран доступ ко всем сайтам. Страница обновлена после включения. Пункт про неподписанные расширения включён в этом запуске Safari.

**Кнопка «Обновить фильтры» пишет, что расширение не включено.**  
Так и есть, пока в Safari не стоит галочка QuietSafari Content Blocker. Включите её и нажмите кнопку ещё раз. Даже без этого встроенный список подхватывается в момент включения расширения.

**Xcode просит пароль снова и снова.**  
В окне пароля нажмите Always Allow, а не Allow один раз.

Подробности, если захотите их кому-то переслать: откройте приложение «Консоль» (Console), в поиске наберите `QuietSafari` и повторите действие.
