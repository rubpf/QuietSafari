Три шага

Three steps

1
Скачать и открыть Download and open

Распакуйте QuietSafari.zip. Если macOS говорит «повреждено», откройте Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть». Либо: xattr -dr com.apple.quarantine и путь к приложению.

Unzip QuietSafari.zip. If macOS says the app is damaged, open System Settings → Privacy & Security → Open Anyway. Or run xattr -dr com.apple.quarantine on the app.

2
Разрешить неподписанные расширения Allow unsigned extensions

Safari → Настройки → Дополнительно → «Показывать функции для веб-разработчиков». Затем меню «Разработка» → «Разрешить неподписанные расширения». Safari забывает этот пункт, когда его закрывают.

Safari → Settings → Advanced → Show features for web developers. Then Develop → Allow Unsigned Extensions. Safari forgets this when it quits.

3
Четыре галочки Four checkboxes

Дополнения: QuietSafari, Content Blocker, Privacy, Russian. У QuietSafari разрешите все сайты. При первом запуске приложение само покажет эти шаги.

Extensions: QuietSafari, Content Blocker, Privacy, Russian. Allow QuietSafari on every website. The app shows these steps on first launch.

FAQ

Почему галочки сбрасываются?

Why do the checkboxes reset?

Сборка без платной подписи Apple. Safari выключает «Разрешить неподписанные расширения», когда его полностью закрывают. QuietSafari тогда пишет: «Safari сбросил разрешение — включить снова».

The build has no paid Apple signature. Safari turns off Allow Unsigned Extensions when it quits. QuietSafari then says the permission was reset.

Куда уходят данные?

Where does data go?

Никуда. Правила и настройки остаются на этом Mac. Кнопка «Обновить фильтры» только скачивает публичные списки EasyList, EasyPrivacy и RU AdList.

Nowhere. Rules and settings stay on this Mac. Update filters only downloads the public EasyList, EasyPrivacy, and RU AdList files.

Which macOS?

macOS 14 или новее. iPhone эта сборка не покрывает.

macOS 14 or later. This build does not cover iPhone.
